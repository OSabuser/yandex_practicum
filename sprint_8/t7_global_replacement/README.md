# Задача №7 - "Глобальная замена"

Будем говорить, что строка `s`  является повтором длины `k`, если существует такая строка `t`, что 
`s=t*k`, где под умножением подразумевается конкатенация `k` экземпляров строки `t` один за другим.
Например, строка `abababab` является повтором строки `abab` длины `2` а также повторением строки `ab` 
`4`. Тогда имеет смысл говорить о наибольшем повторе. Строка является наибольшим повтором длины `k`, если она является 
повтором некоторой строки длины`k` и если не существует такой строки `t`, что `s` – повтор `t` длины `m>k`.
Например, строка `aaaa` является наибольшим повтором длины `4`.

Вам дана строка, которая является наибольшим повтором длины `x`. Найдите `x`.

Заметим, что ответ всегда равен хотя бы единице, так как строка является повтором самой себя.

## Формат ввода

В единственной строке дана строка, состоящая из строчных букв английского алфавита и не превышающая в длину $10^6$.
Строка не бывает пустой.

## Формат вывода

Выведите единственное число — `x`, длину наибольшего повтора.

## Идея

Пусть $n$ — длина всей строки $s$. Префиксная функция `prefix[n-1]` (последний элемент массива) показывает длину 
наибольшего собственного префикса строки, который одновременно является её суффиксом.
Обозначим L = prefix[n-1].
1.	Длина «периода» (минимальной повторяющейся части) равна $k = n - L$.
2.	Если $n$ делится на $k$ без остатка ($n \% k == 0$), то это означает, что строка полностью состоит из повторяющегося фрагмента длины $k$. 
Значит, количество повторений $x = n / k$.
3.	Если $n$ не делится на $k$, значит, строка не является идеальным повтором, кроме как самой себя (то есть $x = 1$).
