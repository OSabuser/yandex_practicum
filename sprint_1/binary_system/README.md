# Двоичная система
> Тимофей записал два числа в двоичной системе счисления и попросил Гошу вывести их сумму, также в двоичной системе. Встроенную в язык программирования возможность сложения двоичных чисел применять нельзя. Помогите Гоше решить задачу.
Решение должно работать за `O(N)`

## Формат ввода
> Два числа в двоичной системе счисления, каждое на отдельной строке. Длина каждого числа не превосходит
10000 символов.

## Формат вывода
> Одно число в двоичной системе счисления


## Идея
- Начинать итерацию со старших разрядов чисел. Использовать два указателя на индексы разрядов двух чисел, а также специальную переменную - **бит переноса**, который равен `1` в случае, если сумма двух бит с битом переноса `> 1`;
- В случае, если один из указателей стал `< 0`, значение бита для соответствующего числа принимается равным `0`
- Итерация продолжается до тех пор, пока все указатели не станут `< 0` (закончатся значащие биты в числах) и бит переноса не станет равен `0`
