# Проверка палиндрома

## Условие задачи

Дана строка. Нужно определить, является ли она палиндромом — то есть читается ли она одинаково слева направо и справа налево. При проверке учитываются только буквы и цифры, регистр игнорируется. Строка из одного символа палиндромом не считается.

**Ограничения:** длина строки от 1 до 20 000 символов.

**Примеры:**
- `"madam"` → `TRUE`
- `"A man a plan a canal Panama"` → `TRUE`
- `"hello"` → `FALSE`

## Ход решения

### Наивный подход

Перевернуть строку и сравнить с оригиналом: `text == text[::-1]`. Сложность O(N) по времени и O(N) по памяти — создаётся копия строки.

### Оптимальный подход: два указателя

Используем два указателя — `left` с начала и `right` с конца строки. Сближаем их к центру, пропуская символы, которые не являются буквой или цифрой (`isalnum()`). Если в какой-то момент символы не совпали — не палиндром.

**Сложность:** O(N) по времени, O(1) по дополнительной памяти.

```
left →                ← right
"A man a plan a canal Panama"
  ↑                       ↑   → 'a' == 'a' ✓
```

### Ключевые моменты

- Приводим строку к нижнему регистру до начала проверки
- Пропускаем не-alnum символы обоими указателями независимо
- Строка из одного символа — особый случай, возвращаем `False`
