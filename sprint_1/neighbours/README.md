# Соседи в матрице

## Условие задачи

Дана матрица M×N. Нужно написать функцию, которая для элемента `A[i][j]` возвращает всех его соседей. Соседними считаются элементы сверху, снизу, слева и справа (соседство фон Неймана). Диагональные соседями не считаются.

**Ограничения:** 1 ≤ M, N ≤ 1000.

**Пример:**
```
Матрица:      Таргет: (0, 0)
[ 1  2  3 ]
[ 0  2  6 ]  → соседи: [0, 2]  (снизу и справа)
[ 7  4  1 ]
[ 2  7  0 ]
```

## Ход решения

### Подход

Используем адресацию по фон Нейману. Для каждого из 4 направлений проверяем граничные условия перед добавлением элемента.

**Сложность:** O(1) времени и O(1) памяти — максимум 4 соседа независимо от размера матрицы.

```
       j
    0  1  2
i 0[1  2  3]
  1[0  2  6]
  2[7  4  1]

A[1][1]: сверхu A[0][1]=2, снизu A[2][1]=4,
         слева A[1][0]=0, справа A[1][2]=6
```

### Ключевые моменты

- 4 условия: `i > 0`, `i < rows-1`, `j > 0`, `j < cols-1`
- Результат сортируем перед выводом
- Класс `Matrix` инкапсулирует матрицу и логику работы с ней
