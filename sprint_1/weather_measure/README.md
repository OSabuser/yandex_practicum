# Хаотичность погоды

## Условие задачи

Метеослужба измеряет температуру воздуха каждый день. Хаотичностью называется количество дней, когда температура **строго больше**, чем в предыдущий день (если есть) и в следующий (если есть).

**Ограничения:** 1 ≤ N ≤ 100 000, температура каждого дня не превышает 273 по абсолютному значению.

**Пример:**
```
Вход: [1, 2, 5, 4, 8]
Выход: 2
(хаотичные дни: 3-й день (5>2 и 5>4) и 5-й день (8>4))
```

## Ход решения

### Подход

Один проход по массиву. Первый и последний дни — граничные случаи, обрабатываются отдельно. Средние дни проверяются циклом в диапазоне `[1, n-1)`.

**Сложность:** O(N) по времени, O(1) по дополнительной памяти.

```python
# Первый день: только правый сосед
[1, 2, 5, 4, 8]
 ^
 1 < 2 → не хаотичный

# Последний день: только левый сосед
[1, 2, 5, 4, 8]
             ^
 8 > 4 → хаотичный

# Средние: два соседа
[1, 2, 5, 4, 8]
       ^
 5 > 2 and 5 > 4 → хаотичный
```

### Ключевые моменты

- Единственный день (`n == 1`) — всегда хаотичный по условию задачи
- Граничные дни имеют только одного соседа, поэтому обрабатываются до основного цикла
- Основной цикл `range(1, days - 1)` не захватывает индексы `0` и `days-1`
