# Факторизация

Основная теорема арифметики говорит: любое число раскладывается на произведение простых множителей единственным образом, с точностью до их перестановки. Например:
$8=2*2*2$
$50=2*5*5=5*5*2=5*2*5$
Разложение числа на простые множители называется факторизацией числа.Напишите программу, которая производит факторизацию переданного числа.

## Формат ввода

На вход подается целое число $2<=n<=10^9$

## Формат вывода

Выведите в порядке неубывания простые множители, на которые раскладывается число `n`
