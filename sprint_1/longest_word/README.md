# Наидлиннейшее слово

## Условие задачи

Дана строка, состоящая из слов, разделённых пробелами. Нужно найти наидлиннейшее слово и вывести его и его длину. Если таких слов несколько, выводится первое из них.

**Ограничения:** длина строки от 1 до 100 000 символов.

**Пример:**
```
Вход: "i love segment tree"
Выход: segment
       7
```

## Ход решения

### Подход

Один проход по списку слов. Храним индекс текущего максимального (`max_index`) и его длину (`max_length`). При строгом неравенстве (`>`) первое из равных остаётся максимальным автоматически.

**Сложность:** O(N) по времени, O(1) по дополнительной памяти.

```python
max_index = 0
max_length = len(words[0])
for index, word in enumerate(words):
    if len(word) > max_length:   # строгое >: побеждает первое из равных
        max_length = len(word)
        max_index = index
```

### Ключевые моменты

- `split()` без аргументов автоматически убирает любые пробелы (начальные, конечные, множественные)
- Функция возвращает `(index, length)`, а не само слово — так удобнее тестировать
- Контроль длины строки делается до `split()`, чтобы не зависеть от последующей обработки
