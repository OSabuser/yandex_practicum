# Значение функции

## Условие задачи

Даны целые числа `a`, `b`, `c`, `x`. Нужно вычислить значение квадратичной функции:

```
f(x) = a·x² + b·x + c
```

**Ограничения:** все числа целые, результат возвращается как `int`.

**Примеры:**
- `a=-8, b=-2, c=7, x=-5` → `-183`
- `a=8, b=9, c=-10, x=2` → `40`
- `a=0, b=0, c=7, x=0` → `7`

## Ход решения

### Подход

Прямое вычисление по формуле за O(1). Никакого перебора, никаких структур данных.

```python
def get_func_value(a, x, b, c):
    return int(a * x * x + b * x + c)
```

### Ключевые моменты

- Порядок аргументов в функции `(a, x, b, c)` отличается от математического `(a, b, c, x)` — важно не запутаться
- `int()` на выходе гарантирует целочисленный результат
- `x * x` вместо `x ** 2` — незначительно, но явнее
