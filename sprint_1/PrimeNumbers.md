# Задача поиска простых чисел

Число 1 не считается простым по определению, этот случай можно обработать отдельно.

Для остальных чисел будем выполнять проверку: если число n*n* делится без остатка на какое-то число *i*, такое, что $1<i<n$, то *n* — составное.

Нужно отдельно протестировать, что число 2 будет считаться простым. Это важный особый случай, потому что не существует целых чисел между 1 и 2, а значит, проверка делимости ни разу не будет выполнена.

Наивная реализация:

```python
# Сложность O(n)
def is_prime(n):
    if n == 1:
        return False
    i = 2
    while i < n:
        if n % i == 0:
            return False
        i = i + 1
    return True
```

Можно решить эту задачу быстрее. Проверять числа, которые больше чем $\sqrt{n}$, необязательно. Если у числа *n* есть делитель, больший $\sqrt{n}$, то существует и делитель, меньший $\sqrt{n}$. А его мы проверим раньше.

```python
# Сложность O(sqrt[n])
def is_prime(n):
    if n == 1:
        return False
    i = 2
    while i * i <= n:
        if n % i == 0:
            return False
        i = i + 1
    return True
```

Сложность алгоритма - $O(\sqrt{n})$ , в худшем случае мы проверим все числа, не превосходящие $\sqrt{n}$

$i\cdot i<=n$ предпочтительнее $i <= \sqrt(n)$ , так как операция вычисления корня "очень дорогая" и выполняется дольше умножения.

Кстати, с помощью функции `is_prime(n)` можно **найти все простые числа, не больше числа** *n*.

Для этого заведём пустой массив `smaller_primes`. Будем проверять все числа, меньшие или равные *n*, на простоту. Если число простое, добавим его в массив `smaller_primes`. В конце работы алгоритма в этом массиве будет содержаться ответ.

Наивная реализация:

```python
def get_smaller_primes(n):
    smaller_primes = []
    for num in range(2, n + 1):
        if is_prime(num):
            smaller_primes.append(num)
    return smaller_primes
```

Один из оптимальных методов - **решето Эратосфена**

Алгоритм такой:

1. Выписываем все целые числа от 0 до *n*. Сразу помечаем, что числа 0 и 1 не являются простыми (записываем на соответствующих этим числам позициях `False`).
2. Заводим переменную `num`, равную первому не рассмотренному простому числу. Изначально она равна 2.
3. Помечаем в списке числа от *2⋅num* до *n* с шагом, равным *num*, составными. Например, для 2 пометим значением `False` чётные числа — 4, 6, 8 и так далее.
4. Теперь в `num` присваиваем следующее простое число, то есть следующее не рассмотренное число в списке. Для этого достаточно увеличивать `num` с шагом 1, пропуская числа, отмеченные как составные. На первом найденном простом числе следует остановиться.
5. Повторяем два предыдущих шага, пока это возможно.

```python
def eratosthenes(n):
    numbers = list(range(n + 1))
    numbers[0] = numbers[1] = False
    for num in range(2, n):
        if numbers[num]:
            for j in range(2 * num, n + 1, num):
                numbers[j] = False
    return numbers
```

Алгоритм можно оптимизировать. Для каждого простого числа *p* начнём отмечать числа, начиная с $p^2$, как составные. Ведь все составные числа, которые меньше его, будут уже рассмотрены.

```python
def eratosthenes_effective(n):
    numbers = list(range(n + 1))
    numbers[0] = numbers[1] = False
    for num in range(2, n):
        if numbers[num]:
            for j in range(num * num, n + 1, num):
                numbers[j] = False
    return numbers
```

Решето Эратосфена работает за $O(n \cdot log⁡_2(log⁡_2n))$. Чтобы это доказать, нужно знать некоторые сложные факты из теории чисел, которые ты пока не изучил. По коду видно, что он работает не за линейное время. Это происходит, поскольку составные числа могут «вычёркиваться» несколько раз. Например, число 10 будет сначала помечено составным как кратное 2, а потом мы пометим его ещё раз, когда будем перебирать числа, кратные 5.

Существует метод решения задачи нахождения всех простых чисел, не превосходящих n*n*, которому требуется $O(n)$ операций. Он называется **линейное решето**. Этот метод помечает каждое число как составное только один раз.

Как и прежде, мы будем перебирать числа в порядке увеличения. Только в отличие от классического решета Эратосфена, составные числа не вычёркиваются. Вместо этого для каждого числа *x* мы запишем наименьший простой делитель *p*. В программе мы будем записывать этот делитель в ячейку массива $lp(x)$ (от англ. *least prime*).

Каждое число будет помечено только один раз, на шаге $i=\frac{x}{p}$. Число *i* может быть взято только одним способом, потому что у любого числа существует только один ***наименьший*** простой делитель *p*.

Алгоритм такой:

1. Для каждого числа `i` будем хранить `lp[i]` — минимальный простой делитель числа `i`. Заведём массив `lp` длины `n + 1`. А также массив `primes`, в который будем добавлять найденные простые числа.
2. Перебираем `i` по возрастанию.
3. Если `lp[i] = 0`, можно сделать вывод, что число `i` простое, и добавить его в массив `primes`.
4. Рассматриваем все простые числа `p`, которые не больше `lp[i]`. Обновляем `lp[p * i] = p`.

```python
def get_least_primes_linear(n):
    lp = [0] * (n + 1)
    primes = []
    for i in range(2, n + 1):
        if lp[i] == 0:
            lp[i] = i
            primes.append(i)
        for p in primes:
            x = p * i
            if (p > lp[i]) or (x > n):
                break
            lp[x] = p
    return primes, lp
```
