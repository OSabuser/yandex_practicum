# Счастливые числа

## Условие задачи

Игрок нажимает кнопку, и на экране появляются три случайных числа. Если все три числа одной чётности (все чётные или все нечётные) — игрок выигрывает.

**Ограничения:** на вход подаются ровно 3 числа, каждое не превышает 10^9 по абсолютному значению.

**Примеры:**
- `2 4 6` → `WIN` (все чётные)
- `7 11 13` → `WIN` (все нечётные)
- `8 2 9` → `FAIL` (разная чётность)
- `1 2 3 4` → `ERROR` (не 3 числа)

## Ход решения

### Наивный подход

Попарно сравнивать остаток от деления на  2: `a%2 == b%2 == c%2`. Работает, но требует аккуратной обработки отрицательных чисел.

### Оптимальный подход

Используем `all()` с генераторным выражением. Проверяем два условия: либо все чётные, либо все нечётные.

**Сложность:** O(N) по времени, O(1) по памяти.

```python
# Ключевая идея:
all(n % 2 == 0 for n in lst) or all(n % 2 != 0 for n in lst)
```

### Ключевые моменты

- Для отрицательных чисел `n % 2 != 0` работает корректно: `-3 % 2 == 1` в Python
- `n % 2 == 1` даст `False` для `-3`, поэтому лучше использовать `!= 0`
- Валидация входа (3 элемента, ограничение по значению) делается до основной логики
