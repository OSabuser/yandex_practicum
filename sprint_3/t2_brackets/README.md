# Задача №3 - "Генератор скобок"

Рита по поручению Тимофея наводит порядок в правильных скобочных последовательностях (ПСП), состоящих только из круглых скобок `()`. Для этого ей надо сгенерировать все ПСП длины $2n$ в алфавитном порядке —– алфавит состоит из `(` и `)` и открывающая скобка идёт раньше закрывающей.

Помогите Рите —– напишите программу, которая по заданному n*n* выведет все ПСП в нужном порядке.

Рассмотрим второй пример. Надо вывести ПСП из четырёх символов. Таких всего две:

1. `(())`
2. `()()`

`(())` идёт раньше `()()`, так как первый символ у них одинаковый, а на второй позиции у первой ПСП стоит `(`, который идёт раньше `)`.

## Формат ввода

На вход функция принимает $n$ — целое число от $0$ до $10$.

## Формат вывода

Функция должна напечатать все возможные скобочные последовательности заданной длины в алфавитном (лексикографическом) порядке.

## Идеи

Есть два ограничения:

1. Не используем больше $n$ открывающих скобок;
2. В любой момент число закрывающих не превышает число открывающих скобок (иначе последовательность станет неправильной).

Из таких ограничений алфавитный порядок автоматически получается, если в рекурсии всегда сначала пробуем добавить  $($ , а потом  $)$ .

### Идея рекурсивного решения
Заведём функцию  gen(pref, open, close) , где:
	•	 `pref`  — уже построенный префикс скобочной последовательности;
	•	 `open`  — сколько открывающих уже поставили;
	•	 `close`  — сколько закрывающих уже поставили.
На каждом шаге:
	•	если  `open == n`  и  `close == n` , печатаем  `pref` ;
	•	если  `open < n` , можно добавить  `(`  и вызвать  `gen(pref + "(", open + 1, close)` ;
	•	если  `close < open` , можно добавить  `)`  и вызвать  `gen(pref + ")", open, close + 1)` .
Так как сначала идёт переход с  `(` , а потом с  `)` , лексикографический порядок по алфавиту  (  $<$  )  выполняется автоматически.

# Пошаговый разбор алгоритма генерации ПСП для n = 3

## Алгоритм

```python
def get_sequence_len():
    return int(input())


def show_correct_sequence(n):
    def generate_brackets_sequence(prefix, opened, closed):
        if opened == n and closed == n:
            # Количество закрывающих и открывающих скобок равны => имеем ПСП
            print(prefix)
            return
        if opened < n:
            generate_brackets_sequence(prefix + "(", opened + 1, closed)
        if closed < opened:
            generate_brackets_sequence(prefix + ")", opened, closed + 1)

    generate_brackets_sequence(prefix, 0, 0)


if __name__ == "__main__":
    seq_length = get_sequence_len()
    prefix = ""
    show_correct_sequence(
        seq_length,
    )

```

## Обозначения

- `prefix` — текущая строка
- `opened` — счётчик, сколько `(` уже поставили
- `closed` — счётчик, сколько `)` уже поставили
- Начальный вызов: `generate_brackets_sequence('', 0, 0)`

## Правила ветвления

1. Если `open_cnt < n` → добавляем `'('` и углубляемся рекурсивно
2. Если `close_cnt < open_cnt` → добавляем `')'` и углубляемся рекурсивно
3. Если `open_cnt == n` и `close_cnt == n` → печатаем строку и возвращаемся

Из-за того, что сначала всегда пробуем `'('`, а потом `')'`, и `'(' < ')'` по алфавиту — вывод автоматически получается лексикографическим.

## Ветка 1 → `((()))`

```
generate_brackets_sequence('', 0, 0)
  → '(' → generate_brackets_sequence('(', 1, 0)
    → '(' → generate_brackets_sequence('((', 2, 0)
      → '(' → generate_brackets_sequence('(((', 3, 0)
        → ')' → generate_brackets_sequence('((()', 3, 1)
          → ')' → generate_brackets_sequence('((())', 3, 2)
            → ')' → generate_brackets_sequence('((()))', 3, 3)
              ✅ Печатаем: ((()))
```
