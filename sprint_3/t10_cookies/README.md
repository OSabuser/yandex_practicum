# Задача №10 - "Печеньки"

К Васе в гости пришли одноклассники. Его мама решила угостить ребят печеньем.

Но не всё так просто. Печенья могут быть разного размера. А у каждого ребёнка есть фактор жадности —– минимальный размер печенья, которое он возьмёт. Нужно выяснить, сколько ребят останутся довольными в лучшем случае, когда они действуют оптимально.

Каждый ребёнок может взять не больше одного печенья.


## Формат ввода

В первой строке задано $n$ - количество детей.
Во второй - $n$ чисел, разделенных пробелом, каждое из которых - фактор жадности ребенка.
Это натуральные числа не превосходящие $1000$.
В следующей строке записано число $m$ - количество печенек.
Далее - $m$ натуральных чисел, разделённых пробелом - размеры печенек (не превосходящие $1000$).
Оба числа $n$ и $m$ не превосходят $10000$.


## Формат вывода

Нужно вывести одно число –— количество детей, которые останутся довольными


## Идея

1. Отсортировать массив размеров печенек по возрастанию.
2. Отсортировать массив факторов жадности детей по возрастанию.
3. Дальше идти двумя указателями:
- один по детям (от самого «скромного»),
- другой по печеньям (от самого маленького).
- Если текущему ребёнку хватает текущего печенья (size_cookie ≥ greed_child), считаем ребёнка довольным и двигаем оба указателя.
- Если не хватает — печенье слишком маленькое, двигаем указатель печенья вперёд, ищем побольше.
- Когда одна из последовательностей закончилась, останавливаемся; количество довольных детей — это число удачных совпадений.
