# Задача №4 - "Фибоначчи для взрослых"

Гоша практикуется в динамическом программировании — он хочет быстро считать числа Фибоначчи.
Напомним, что числа Фибоначчи определены как последовательность $F_{n},n=0,1 \cdot F_0=F_1=1, F_n=F_{n-1}+F_{n-2},n \geq 2$.
Помогите Гоше решить эту задачу.

## Формат ввода

В единственной строке дано целое число  `n` ($1 \leq n \leq 10^5$).

## Формат вывода

Вычислите значение $F_n$ по модулю $10^9 +7$ и выведите его.

## Идея

1. Оптимизация памяти $$O(1)$: Нам не нужно заводить огромный массив на $$10^5$ элементов.
Чтобы вычислить текущее число Фибоначчи, нам нужно знать только два предыдущих.
Поэтому мы просто заведем две переменные и будем их «сдвигать» на каждом шаге.
2. Арифметика остатков: По условию ответ нужно вывести по модулю $10^9 + 7$. В Python целые числа не имеют
ограничения по размеру, но сложение гигантских чисел начнёт сильно тормозить программу. Если мы будем брать остаток от деления % $10^9 + 7$ на каждом шаге, числа всегда будут оставаться маленькими, а сложение будет работать за честное $O(1)$. Математика модулей гарантирует, что итоговый ответ от этого не изменится.
