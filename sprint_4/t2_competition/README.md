# Задача №2 - "Соревнование"

Жители Алгосов любят устраивать турниры по спортивному программированию. Все участники разбиваются на пары и соревнуются друг с другом. А потом два самых сильных программиста встречаются в финальной схватке, которая состоит из нескольких раундов. Если в очередном раунде выигрывает первый участник, в таблицу с результатами записывается $0$, если второй, то $1$. Ничьей в раунде быть не может.

Нужно определить наибольший по длине непрерывный отрезок раундов, по результатам которого суммарно получается ничья. Например, если дана последовательность $0010111000$, то раунды с 2-го по 9-й (нумерация начинается с единицы) дают ничью.

## Формат ввода

В первой строке задаётся $n, 0 \leq n \leq 10^5$ — количество раундов. Во второй строке через пробел записано 
$n$ чисел –— результаты раундов. Каждое число равно либо $0$, либо $1$.


## Формат вывода

Выведите длину найденного отрезка.


## Идея

### Шаг 1. Преобразование 0 и 1 в −1 и 1

Пусть исходный результат раундов – последовательность из 0 и 1:
- 0 – выиграл первый участник;
- 1 – выиграл второй участник.
Заменяем:
- каждый 0 на -1;
- каждый 1 оставляем как 1.
Тогда:
- сумма на отрезке равна 0 ⇔ на отрезке одинаковое число нулей и единиц ⇔ отрезок даёт ничью.
Таким образом, задача сводится к поиску максимального по длине подотрезка с нулевой суммой.

### Шаг 2. Префиксные суммы

Определим префиксную сумму $pref[i] = a_1 + a_2 + \dots + a_i$, где $a_i$ – элементы преобразованного массива (-1 или +1).
Сумма на отрезке $sum(l,r)=pref[r] - pref[l-1]$
Отрезок даёт ничью ⇔ его сумма равна 0 $sum(l,r)=0<=>ref[r]=pref[l-1]$

То есть, всякий раз, когда **префиксная сумма повторяется**, промежуток между первым и текущим появлением этой суммы – отрезок с суммой 0.

### Шаг 3. Хранение первого вхождения каждой суммы

Идём по массиву слева направо и поддерживаем:
- текущую префиксную сумму `pref`;
- словарь/хэш-таблицу `first`, где храним самую левую позицию появления каждой суммы:
- $first[sum_value] = индекс$.

Инициализация:
- до начала массива сумма равна `0`, поэтому кладём  `first = 0`.

Дальше для каждой позиции  `i`:
1.	Обновляем  `pref`  с учётом текущего элемента (-1 для 0, 1 для 1).
2.	Если  `pref` уже есть в `first`, то:
- отрезок от  `firstpref + 1`  до  `i`  имеет суммарную сумму `0`;
- длина этого отрезка $length=i-first[pref]`
- обновляем максимум длины, если `length` больше текущего.
3.	Если  `pref` ещё нет в  `first`, записываем:
- $first[pref]=i$  – мы запоминаем самое левое вхождение этой суммы.
