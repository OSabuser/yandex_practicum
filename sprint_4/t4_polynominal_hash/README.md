# Задача №4 - "Полиноминальный хэш"

Алле очень понравился алгоритм вычисления полиномиального хеша. Помогите ей написать функцию, вычисляющую хеш строки s. В данной задаче необходимо использовать в качестве значений отдельных символов их коды в таблице ASCII.

Полиномиальный хеш считается по формуле:

$h(s)=(s_{1}a^{n-1}+s_{2}a^{n-2}+ \cdots + s_{n-1}a+s_{n})modm$

## Формат ввода

- В первой строке дано число $a(1 \leq a \leq 1000)$ — основание, по которому считается хеш.
- Во второй строке дано число $m(1 \leq m \leq 10^{9})$ — модуль.
- В третьей строке дана строка $s(0 \leq \vert s \vert \leq 10^{6})$

## Формат вывода

Выведите целое неотрицательное число –— хеш заданной строки.
